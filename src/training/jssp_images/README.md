# JSSP Image-Based Training

This folder trains CNN models to select good solvers for Job Shop Scheduling Problem (JSSP) instances using **grayscale images** (128×128×1) generated by [`src/data_generation/jssp_images`](src/data_generation/jssp_images/README.md).

Supported training tasks (via CLI):

- **classification** – predict the single best solver per instance
- **multilabel** – predict all solvers that solve the instance within a time limit

---

## Folder contents

- [`cli.py`](src/training/jssp_images/cli.py) – command-line entry point for training
- [`config.yaml`](src/training/jssp_images/config.yaml) – main experiment, data, model, and training settings
- [`data_utils.py`](src/training/jssp_images/data_utils.py) – CSV loading, label building, image dataset creation
- [`model_builder.py`](src/training/jssp_images/model_builder.py) – CNN architecture definition
- [`training_loop.py`](src/training/jssp_images/training_loop.py) – K-fold cross-validation and training loop
- [`evaluation.py`](src/training/jssp_images/evaluation.py) – metrics and per-fold evaluation
- [`visualization.py`](src/training/jssp_images/visualization.py) – plots and diagnostic figures
- [`__init__.py`](src/training/jssp_images/__init__.py) – Python API exports

---

## Inputs

The training CLI expects a CSV like the one generated by [`src/data_generation/jssp_images`](src/data_generation/jssp_images/README.md), for example:

- [`data/jssp/datasets/jssp_cnn_data_images/ground_truth_jsp_generated_dataset.csv`](data/jssp/datasets/jssp_cnn_data_images/ground_truth_jsp_generated_dataset.csv)

Required columns:

- `Image_Npy_Path` – path to a `.npy` grayscale image (relative or absolute)
- `*_Runtime_s` – runtime columns for each solver (e.g. `CBC_DEF_Runtime_s`)
- optionally `*_Score_S_rel` – relative score per solver (used with `--use_score`)

Image paths are normalized and checked by [`data_utils.py`](src/training/jssp_images/data_utils.py).

## CLI usage (from project root)

Run the training pipeline via [`cli.py`](src/training/jssp_images/cli.py):

```bash
python -m src.training.jssp_images.cli --csv <csv_path> --task <classification|multilabel> [options]
```

### 1. Basic classification run

Use all solvers available in the CSV, default config values:

```bash
python -m src.training.jssp_images.cli \
  --csv data/jssp/datasets/jssp_cnn_data_images/ground_truth_jsp_generated_dataset.csv \
  --task classification
```

### 2. Basic multilabel run

```bash
python -m src.training.jssp_images.cli \
  --csv data/jssp/datasets/jssp_cnn_data_images/ground_truth_jsp_generated_dataset.csv \
  --task multilabel
```

---

### 3. Use custom config and override key hyperparameters

Start from [`config.yaml`](src/training/jssp_images/config.yaml) but override some options from the CLI:

```bash
python -m src.training.jssp_images.cli \
  --config src/training/jssp_images/config.yaml \
  --csv data/jssp/datasets/jssp_cnn_data_images/ground_truth_jsp_generated_dataset.csv \
  --task classification \
  --epochs 50 \
  --batch_size 64 \
  --learning_rate 0.01 \
  --folds 10
```

---

### 4. Train on a subset of solvers

Suppose the CSV has runtime columns:

- `CBC_DEF_Runtime_s`
- `SCIP_DEF_Runtime_s`
- `HIGHS_DEF_Runtime_s`
- `CPLEX_DEF_Runtime_s`
- `GUROBI_DEF_Runtime_s`

You can restrict training to a subset via `--solvers` (names without suffix):

```bash
python -m src.training.jssp_images.cli \
  --csv data/jssp/datasets/jssp_cnn_data_images/ground_truth_jsp_generated_dataset.csv \
  --task classification \
  --solvers CBC_DEF,SCIP_DEF,CPLEX_DEF \
  --epochs 30 \
  --folds 5
```

Multilabel with all five solvers:

```bash
python -m src.training.jssp_images.cli \
  --csv data/jssp/datasets/jssp_cnn_data_images/ground_truth_jsp_generated_dataset.csv \
  --task multilabel \
  --solvers CBC_DEF,SCIP_DEF,HIGHS_DEF,CPLEX_DEF,GUROBI_DEF \
  --epochs 25
```

If `--solvers` is omitted, all detected solver columns are used.

---

### 5. Use scores instead of runtimes

If your CSV includes `*_Score_S_rel` columns, you can base “best solver” selection on scores:

```bash
python -m src.training.jssp_images.cli \
  --csv data/jssp/datasets/jssp_cnn_data_images/ground_truth_jsp_generated_dataset.csv \
  --task classification \
  --use_score
```

---

### 6. Control time limit and output location

Override the time limit used for multilabel labels and resolved-rate metrics:

```bash
python -m src.training.jssp_images.cli \
  --csv data/jssp/datasets/jssp_cnn_data_images/ground_truth_jsp_generated_dataset.csv \
  --task multilabel \
  --time_limit 120
```

Send outputs to a custom parent directory with a custom run name:

```bash
python -m src.training.jssp_images.cli \
  --csv data/jssp/datasets/jssp_cnn_data_images/ground_truth_jsp_generated_dataset.csv \
  --task classification \
  --out_parent results/jssp/custom_runs \
  --run_name my_jssp_cnn_run
```

Set a specific random seed:

```bash
python -m src.training.jssp_images.cli \
  --csv data/jssp/datasets/jssp_cnn_data_images/ground_truth_jsp_generated_dataset.csv \
  --task classification \
  --seed 123
```

## Configuration (summary)

Full defaults are in [`config.yaml`](src/training/jssp_images/config.yaml). Main sections:

- `experiment` – name, description, seed
- `data` – CSV path, image size (128×128×1), time limit, `use_score`
- `model` – CNN architecture (filters, kernel sizes, dense units, dropout)
- `training` – epochs, batch size, SGD + Nesterov learning rate and momentum schedule, k-folds, early stopping
- `output` – parent directory, timestamp format, and what to save per fold
- `classification` / `multilabel` – per-task metrics and plots to generate

The CLI can override most important settings (`--epochs`, `--batch_size`, `--folds`, `--learning_rate`, `--time_limit`, `--out_parent`, `--run_name`, `--seed`).

## Outputs

Each run creates a timestamped directory under `results/jssp/images` (unless overridden):

```text
results/jssp/images/<run_name>_<task>_YYYYMMDD_HHMMSS/
├── config.yaml               # effective config used
├── run_info.json             # CLI arguments, CSV path, timestamp
├── metrics_per_fold.csv      # per-fold metrics table
├── metrics_summary.json      # aggregated statistics (mean, std, etc.)
├── <metric>_per_fold.png  # metric vs fold plot
└── fold_1/, fold_2/, ...     # per-fold predictions, metrics, plots
```

Per-fold folders include:

- `fold*_y_true.npy`, `fold*_y_pred.npy` (and for multilabel: `fold*_y_scores.npy`)
- task-specific reports and plots (e.g. confusion matrices, F1 per label)

## Python API (optional)

You can use the module directly in Python instead of the CLI:

```python
import pandas as pd
from src.training.jssp_images import load_config, detect_solver_cols, run_kfold

config = load_config("src/training/jssp_images/config.yaml")
df = pd.read_csv(
    "data/jssp/datasets/jssp_cnn_data_images/ground_truth_jsp_generated_dataset.csv"
)

solver_cols = detect_solver_cols(df)

fold_results, summary = run_kfold(
    df=df,
    task="classification",
    solver_cols=solver_cols,
    use_score=False,
    config=config,
    root_outdir="results/jssp/images/manual_run",
)

print("Accuracy mean:", summary["mean"])
```

(The underlying API also supports a regression task for debugging/ablation, but regression is not exposed through the CLI.)

- Python 3.8+
