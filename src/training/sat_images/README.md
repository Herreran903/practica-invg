# SAT Image-Based Training

This folder trains CNN models to select good solvers for SAT (Boolean Satisfiability) instances using **grayscale images** (128×128×1) generated by [`src/data_generation/sat_images`](src/data_generation/sat_images/README.md).

Supported training tasks (via CLI):

- **classification** – predict the single best solver per instance  
- **multilabel** – predict all solvers that can solve the instance within a time limit

The training pipeline is SAT-specific: it computes additional metrics such as **resolved rate** and **AST (Average Solving Time)** and supports repeated K-fold cross-validation (e.g. 5×5).

---

## Folder contents

- [`cli.py`](src/training/sat_images/cli.py) – command-line entry point for SAT image training
- [`config.yaml`](src/training/sat_images/config.yaml) – data, model, training, SAT-metric, and output settings
- [`data_utils.py`](src/training/sat_images/data_utils.py) – CSV loading, label building, feature-time handling, SAT-specific helpers
- [`model_builder.py`](src/training/sat_images/model_builder.py) – CNN architecture configuration (shared with JSSP images, tuned via config)
- [`training_loop.py`](src/training/sat_images/training_loop.py) – K-fold training with repetitions and aggregation of SAT metrics
- [`evaluation.py`](src/training/sat_images/evaluation.py) – SAT-specific evaluation (resolved rate, AST) built on top of JSSP evaluation
- [`__init__.py`](src/training/sat_images/__init__.py) – Python API exports

## Inputs

The training CLI expects a CSV produced by [`src/data_generation/sat_images`](src/data_generation/sat_images/README.md), for example:

- [`data/sat/datasets/sat_cnn_data_images/ground_truth_aslib.csv`](data/sat/datasets/sat_cnn_data_images/ground_truth_aslib.csv)

Required / typical columns:

- `Image_Npy_Path` – path to a `.npy` grayscale image (relative or absolute)
- `*_Runtime_s` – runtime per solver (e.g. `glucose2_Runtime_s`)
- optional `*_Score_S_rel` – solver scores (if using `--use_score`)
- optional `*_Status` – run status per solver (e.g. `lingeling_Status`)
- optional feature-time column – configured via `data.feat_time_column` in [`config.yaml`](src/training/sat_images/config.yaml)

The CLI normalizes and validates image paths before training.

## CLI usage (from project root)

Run the training pipeline via [`cli.py`](src/training/sat_images/cli.py):

```bash
python -m src.training.sat_images.cli --csv <csv_path> --task <classification|multilabel> [options]
```

### 1. Basic classification run (single 5-fold CV)

```bash
python -m src.training.sat_images.cli \
  --csv data/sat/datasets/sat_cnn_data_images/ground_truth_aslib.csv \
  --task classification
```

Uses default values from [`config.yaml`](src/training/sat_images/config.yaml) for:

- 5-fold CV (`training.k_folds`)
- 1 repetition (`training.k_fold_repeats`)
- time limit (`data.time_limit_s`, default 1200s)
- CNN architecture and optimizer

---

### 2. Basic multilabel run

```bash
python -m src.training.sat_images.cli \
  --csv data/sat/datasets/sat_cnn_data_images/ground_truth_aslib.csv \
  --task multilabel \
  --epochs 30 \
  --time_limit 1200
```

---

### 3. 5×5 cross-validation (classification)

Run 5 folds with 5 repetitions (25 total folds), with a custom time limit:

```bash
python -m src.training.sat_images.cli \
  --csv data/sat/datasets/sat_cnn_data_images/ground_truth_aslib.csv \
  --task classification \
  --folds 5 \
  --repeats 5 \
  --time_limit 1800
```

The `--folds` and `--repeats` options override `training.k_folds` and `training.k_fold_repeats` in [`config.yaml`](src/training/sat_images/config.yaml).

---

### 4. Filter to a subset of solvers

Solver names must match the `algorithm` identifiers used in the ASlib scenario (and the prefixes in the CSV columns, e.g. `glucose2_Runtime_s` → `glucose2`).

```bash
python -m src.training.sat_images.cli \
  --csv data/sat/datasets/sat_cnn_data_images/ground_truth_aslib.csv \
  --task classification \
  --solvers ebglucose,glucose2,lingeling,clasp1,clasp2 \
  --folds 5 \
  --repeats 5 \
  --time_limit 1200
```

The CLI will:

- keep `<solver>_Runtime_s` (required)
- keep `<solver>_Score_S_rel` if present
- keep `<solver>_Status` if present

---

### 5. Use a feature-extraction time column

If the CSV contains a column with feature-extraction time (e.g. `Feature_Extract_s`), pass it so AST is computed as `feature_time + runtime`:

```bash
python -m src.training.sat_images.cli \
  --csv data/sat/datasets/sat_cnn_data_images/ground_truth_aslib.csv \
  --task classification \
  --folds 5 \
  --repeats 5 \
  --time_limit 1800 \
  --feat_time_col Feature_Extract_s
```

If no feature-time column is provided or configured, the code assumes 0 seconds for features.

---

### 6. Custom output directory and run name

By default results go under `results/sat/`. You can override the parent directory and run name:

```bash
python -m src.training.sat_images.cli \
  --csv data/sat/datasets/sat_cnn_data_images/ground_truth_aslib.csv \
  --task multilabel \
  --out_parent results/sat/custom_runs \
  --run_name sat_images_experiment \
  --folds 5 \
  --repeats 5
```

Set a specific random seed:

```bash
python -m src.training.sat_images.cli \
  --csv data/sat/datasets/sat_cnn_data_images/ground_truth_aslib.csv \
  --task classification \
  --seed 123
```

## Configuration (summary)

Full defaults are in [`config.yaml`](src/training/sat_images/config.yaml). Main sections:

- `experiment` – name, description, version
- `data` – image size, time limit, feature-time column, image path column
- `model` – CNN architecture (filters `[32, 64, 128]`, kernel sizes `[3, 2, 2]`, dropout, dense units `[1000, 200]`)
- `training` – epochs, batch size, SGD + Nesterov learning rate schedule, K-folds, K-fold repetitions, early stopping, seed
- `output` – parent directory (`results/sat`), run name prefix, timestamp format, whether to append task name
- `sat` – valid/invalid statuses and SAT-specific options
- `tasks.classification` / `tasks.multilabel` – per-task activation, loss, metrics, threshold, and whether to compute `resolved_rate` and `AST`

The CLI can override many of these at runtime (`--epochs`, `--batch_size`, `--folds`, `--repeats`, `--learning_rate`, `--time_limit`, `--feat_time_col`, `--out_parent`, `--run_name`, `--seed`).

Regression is not exposed via the CLI for SAT images.

## Outputs

Each run creates a timestamped directory under `results/sat` (unless overridden), for example:

```text
results/sat/sat_images_cnn_classification_YYYYMMDD_HHMMSS/
├── config.yaml
├── run_info.json
├── metrics_summary_GLOBAL.json      # global stats across all folds × repeats
├── metrics_summary_per_rep.csv      # per-repetition aggregates
├── rep_1/
│   ├── metrics_per_fold.csv         # per-fold metrics for repetition 1
│   ├── metrics_summary.json         # summary for repetition 1
│   └── fold_1/
│       ├── fold1_metrics.json
│       ├── fold1_y_true.npy
│       ├── fold1_y_pred.npy
│       ├── fold1_resolved_detail.csv
│       └── fold1_confusion.png
└── rep_2/, rep_3/, ...
```

Per-fold metrics include:

- primary task metric (`accuracy` for classification, `f1_micro` for multilabel)
- SAT-specific metrics: `resolved_rate`, `AST_sec` (when configured)
- optional `misclassification_rate` (classification) and other diagnostics

Global summaries aggregate these across all folds and repetitions.

## SAT-specific metrics

For SAT tasks, evaluation (implemented in [`evaluation.py`](src/training/sat_images/evaluation.py)) extends the base JSSP metrics with:

- **Resolved rate**  
  - Classification: fraction of instances where the predicted solver successfully solves within the time limit, considering status and runtime.
  - Multilabel: fraction of instances where at least one predicted solver is successful within the time limit.
- **AST (Average Solving Time)**  
  - Average of `feature_time + solver_runtime` per instance, penalizing failures and timeouts by using the time limit.

Both metrics are aggregated:

- per fold (in `rep_k/metrics_per_fold.csv`)
- per repetition (in `metrics_summary.json` under each `rep_k/`)
- globally across all folds × repetitions (in `metrics_summary_GLOBAL.json`)

## Requirements

Core dependencies (shared with the other training modules, see [`requirements.txt`](requirements.txt)):

- Python 3.8+
- TensorFlow 2.x
- NumPy
- pandas
- scikit-learn
- Matplotlib
- PyYAML

Before training, generate the SAT image dataset with [`src/data_generation/sat_images`](src/data_generation/sat_images/README.md) and ensure the CSV passed to `--csv` exists and contains valid `Image_Npy_Path` entries pointing to `.npy` image files.
